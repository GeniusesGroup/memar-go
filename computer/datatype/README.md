# DataType
[DataType](https://en.wikipedia.org/wiki/Data_type) or Type in computer science and computer programming, is a collection or grouping of data values, usually specified by a set of possible values, a set of allowed operations on these values, and/or a representation of these values as machine types even in compilers or runtime packages.

It can use for any data like CLA flags or json fields or any other data structures.
