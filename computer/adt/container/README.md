# Container
[Container](https://en.wikipedia.org/wiki/Container_(abstract_data_type)) is a data structure whose instances are [collections](https://en.wikipedia.org/wiki/Collection_(abstract_data_type)) of other objects.

In other words, they store objects in an organized way that follows specific access rules.
